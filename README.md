# 몬스터 수학 서바이벌

초등학교 4~6학년을 위한 오리지널 몬스터 수집·진화형 수학 생존 게임입니다. 특정 기존 캐릭터, 이름, 로고, 이미지 리소스를 사용하지 않습니다.

## 실행
- `index.html`을 브라우저에서 열면 실행됩니다.
- 인터넷 연결이 있으면 Google Fonts가 적용됩니다. 폰트 연결이 없어도 기본 폰트로 동작합니다.

## GitHub Pages 배포
1. GitHub에서 새 저장소를 만듭니다. 예: `math-monster-survival`
2. `index.html`, `style.css`, `game.js`를 저장소 루트에 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. **Build and deployment**에서 `Deploy from a branch`를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`를 선택하고 Save를 누릅니다.
6. 잠시 기다리면 `https://<사용자명>.github.io/<저장소명>/` 주소로 공개됩니다.

## 게임 기능
- 초등 4~6학년 수준의 분수, 소수, 비율·백분율, 평균, 부피, 혼합 계산 문제
- 정답 경험치와 레벨업, 콤보, 생존 라운드, 체력 시스템
- 몬스터 해금, 브라우저 로컬 저장, 오늘의 미션 UI
- 모바일 반응형 레이아웃

## 참고
- 현재는 프론트엔드 시제품입니다. 계정 로그인, 서버 저장, 글로벌 랭킹은 포함하지 않습니다.
- 문제의 난이도와 정답 판정은 학습용 기본 버전입니다. 학교별 교육과정에 맞춰 추가 검토할 수 있습니다.
